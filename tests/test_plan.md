# AI 招投标系统 — 测试计划

## 测试范围

覆盖 5 大模块：M1技术问答、M2需求梳理、M3方案生成、M4标书撰写、M5政策打通

## 测试层次

| 层次 | 工具 | 数量 | 执行命令 |
|------|------|------|---------|
| 后端单元测试 | pytest | ~34 | `pytest tests/pytest/` |
| 后端集成测试 | pytest + TestClient | ~14 | `pytest tests/pytest/ -m integration` |
| AI质量Eval | 自定义 | ~16 | `python tests/eval/run_eval.py` |
| 前端组件测试 | vitest | ~15 | `npm test` |
| E2E测试 | Playwright | ~8 | `npx playwright test` |

## 关键测试场景

### M1 技术问答
- [ ] 意图分类：5类意图各10条，准确率≥95%
- [ ] RAG检索：Top-3召回率≥80%
- [ ] NL2SQL安全：SQL注入拦截100%
- [ ] 降级策略：检索无结果/LLM超时

### M4 标书撰写
- [ ] 招标需求提取：完整率≥90%
- [ ] 硬性条款响应率：100%阻塞检查
- [ ] 素材复用：Top-3含至少1条中标记录
- [ ] 格式校验：6项规则覆盖

### E2E 场景
- [ ] 对话问答：输入→意图识别→检索→回答
- [ ] 方案生成：需求→大纲→内容→下载
- [ ] 标书填充：模板→填充→编辑→下载
- [ ] 错误降级：后端不可用时前端降级提示

## 验收标准
- 单元测试通过率 100%
- E2E 核心场景 100% 通过
- AI Eval 准确率 ≥ 90%
- 无 P0/P1 Bug
